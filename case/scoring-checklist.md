# Scoring checklist

Our reading of the rubric as a checklist. Use it to review the PDF, video and deck before submitting. Interpretations are ours, not the organizers'.

## Product Arena (due Oct 20)

**Problem Definition (25%)**
- [ ] One named user role (e.g. "allocation analyst at a 100+ store fashion retailer"), not "retailers"
- [ ] Their current workflow, step by step, with where the delay happens
- [ ] Pain backed by interview quotes **and** industry data
- [ ] "Why this problem first": size of cost, frequency, and fit with SAP

**Problem-Solution Fit (25%)**
- [ ] Each feature maps to a specific pain point (a table works well)
- [ ] Features ranked, with what we deliberately left out and why
- [ ] Before vs after: the same scenario, with time-to-response shown both ways
- [ ] Where AI acts and where a human approves (the case asks this directly)

**Business Viability (25%)**
- [ ] Why a retailer adopts it: ROI with every assumption labeled
- [ ] Why SAP wants it: fits Joule / Business Data Cloud, revenue model, pulls customers to S/4HANA cloud
- [ ] Costs (build, data, change management) compared with benefits
- [ ] How it differs from SAP Retail Intelligence and from Blue Yonder / RELEX / o9

**Research & Evidence (15%)**
- [ ] Every number has a source in the PDF
- [ ] Facts and assumptions visibly marked (e.g. a label or icon)
- [ ] Primary research included: number of interviews and who

**Video (10%)**
- [ ] User, problem, solution and value in 60 seconds
- [ ] A story with one character and one moment, not a feature list
- [ ] Consistent visuals with the PDF

**5-minute skim test**
- [ ] A judge gets the pitch from page 1 alone
- [ ] Headings state conclusions, not topics
- [ ] One visual per page minimum

## Summit (if we advance)

- [ ] Prototype demos the core workflow end to end
- [ ] Implementation plan: team, milestones, dependencies on SAP products, risks, success metrics
- [ ] One prepared answer per stakeholder: engineering, marketing, finance, strategy
- [ ] Limitations stated before judges raise them
